# Task 1: Reverse Number with Sign Preservation

Програма для реверсу цілого числа (не менше 5 цифр) із збереженням його знаку. Нулі на початку числа після реверсу автоматично відсікаються.

## Приклади роботи
- `123` -> `321`
- `1000` -> `1`
- `-453` -> `-354`
